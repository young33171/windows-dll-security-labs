# 실습 증거 캡처

실습 캡처는 직접 촬영한 원본 또는 개인정보 마스킹본만 업로드합니다.

권장 캡처:
- Process Explorer에서 `myhack2.dll` 검색 결과 **1 matching item**
- `SearchProtocolHost.exe`의 DLL 목록에 `myhack2.dll` 표시
- Visual Studio DLL 빌드 완료 출력
- `DLL Load Success!`와 스택 검사 오류(문제 해결 기록)

**주의:** 캡처가 존재하지 않는 실습의 성공 장면은 만들지 않습니다. VM 사용자 이름, 시스템 경로, 개인 정보가 노출되는 곳은 마스킹합니다.
